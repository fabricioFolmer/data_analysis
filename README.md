## Database

Origem: https://archive.ics.uci.edu/dataset/432/news+popularity+in+multiple+social+media+platforms 

### Variáveis do Conjunto de Dados de Notícias

Este conjunto de dados contém informações sobre notícias coletadas de diversas fontes oficiais, incluindo dados de sentimento e popularidade em redes sociais. Abaixo está a descrição das variáveis presentes no dataset:

| Variável              | Tipo       | Descrição                                                                 |
|-----------------------|------------|---------------------------------------------------------------------------|
| `IDLink`              | Numérico   | Identificador único de cada notícia.                                     |
| `Title`               | String     | Título da notícia conforme publicado pela fonte oficial.                 |
| `Headline`            | String     | Manchete da notícia conforme publicado pela fonte oficial.               |
| `Source`              | String     | Veículo de mídia responsável pela publicação da notícia.                 |
| `Topic`               | String     | Tópico utilizado como critério de busca para obtenção da notícia.        |
| `PublishDate`         | Timestamp  | Data e hora da publicação da notícia.                                    |
| `SentimentTitle`      | Numérico   | Pontuação de sentimento associada ao título da notícia.                  |
| `SentimentHeadline`   | Numérico   | Pontuação de sentimento associada à manchete da notícia.                 |
| `Facebook`            | Numérico   | Popularidade da notícia na rede social Facebook.                         |
| `GooglePlus`          | Numérico   | Popularidade da notícia na rede social Google+.                          |
| `LinkedIn`            | Numérico   | Popularidade da notícia na rede social LinkedIn.                         |
